The lecture notes *Wstęp do analizy falkowej z zastosowaniami w matematyce
finansowej* (M. Paluszyński, 2019) are used as background material. The PDF
(`falki.pdf`) is kept locally only and is excluded from the repository by
`.gitignore` until its redistribution rights are confirmed.
